烟山基地 v0.5.3 · 英语战术搜撤行动试玩
更新日期：2026-11-13

【快速开始】
• 标准启动：双击项目根目录「开始烟山试玩.cmd」（或独立包内「开始试玩.cmd」）。
• 低负载启动：双击「低负载启动.cmd」（游戏中按 F6 可随时切换实时阴影）。
• 单机离线直接运行，无需安装 Godot 或联网；完全兼容并保留旧版存档进度。

【v0.5.3 重点升级（双武器近战 · 有限备弹 · 枪匠 2.0 · 首领核心战）】
• 双武器系统与 Blender 战术匕首：新增 [1]/[2]/滚轮 切换「YS-04 卡宾枪 / 战术匕首」及 [V] 快速出刀；持刀 +12% 移速，背后处决必杀小兵并回收 +1 弹匣备弹，同步扩展 `fp_arms.glb` 至 8 套骨骼姿势（含拔刀待机与左右双连斩）；
• 实战有限备弹与局内道具循环：自由靶场保持无限弹药，实战部署为有限备弹；沿山路搜集 7 处 5.56 军用弹药箱、3 处 [G] 烟雾/EMP 手雷与 3 处 [T] 肾上腺素能量饮；
• 枪匠 2.0 与 15 项商店配置：新增 2 倍战术棱镜、钛合金消音器、双室制退器、战术直角握把（全 3D 模型挂载与实时属性联动，支持已购配件点击切换或卸下）及模块化携行弹挂、特战腰带；
• B 区重装首领与反绕过机制：镇守 450 HP 首领「铁甲词尊 · 烟山统领」（3 阶段、胸口弱点核心、召唤无人机与红圈蓄力轰炸，击败必爆 380 币黄金核心与研发图纸）；实战下营地 0 号靶场不计分，撤离需满足 260 分 + 攻克 ≥2 前哨 + 击败 B 区首领。

【操作说明】
• WASD / 方向键：移动    • Shift：冲刺闪避    • 空格：跳跃
• 1 / 2 / 滚轮：切枪切刀 • V：快刀近战        • R：换弹
• 左键：射击 / 挥刀      • 右键（按住）：瞄准（含 2 倍棱镜缩放）
• H：应急医疗包          • G：烟雾/EMP 手雷   • T：肾上腺素能量饮
• Q：朗读当前英文发音    • Tab（破译界面）：播放目标词句发音
• E：开启常规单词箱 / 高阶密码箱 / 弹药道具 / 机关 / 启动撤离
• Esc：暂停 / 关闭面板   • F6：切换阴影画质   • F12：截图
