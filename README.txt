烟山基地 v0.5.2 · 英语战术搜撤行动试玩
更新日期：2026-11-12

【快速开始】
• 标准启动：双击项目根目录「开始烟山试玩.cmd」（或独立包内「开始试玩.cmd」）。
• 低负载启动：双击「低负载启动.cmd」（游戏中按 F6 可随时切换实时阴影）。
• 单机离线直接运行，无需安装 Godot 或联网；完全兼容并保留旧版存档进度。

【v0.5.2 重点升级（Blender 写实人体雕刻战术手臂）】
• 彻底替换早期程序化几何体手臂，基于 Blender 4.5 与 Blender Studio 官方 CC0 人体高模（Human Base Meshes v1.4.1）+ ambientCG 织物/皮革 PBR 贴图，打造真实人体解剖级第一人称战术双臂与半指手套（含自然手指肌肉、裸露指节、真实指甲盖、防刮格纹作战袖与左腕 3D 遥测战术表）；
• 内置 39 根骨骼蒙皮：右手食指精准搭扣扳机并随射击联动，左手 C-clamp 托护前护木，换弹时左手骨骼真实下探抓握弹匣拔插，右键全息开镜 0 遮挡准星，解锁「森林涂装」同步切换林地迷彩衣袖。

【v0.5.1 核心机制与场景精修】
1. 拟真第一人称战术手臂握持（告别悬浮步枪）：
   - 新增防刮迷彩护袖、碳纤维护指战术手套与左腕战术手环，双手自然握持握把与前护木；
   - 开火时食指联动扣扳机，换弹时左手下探抓取弹匣拔插，右键开镜不挡准星，森林涂装同步变色。
2. 营地帐篷与全图补给箱写实化重做（告别早期卡通白模）：
   - 营地升级为可步入做旧橄榄帆布指挥帐篷（含钢管桁架、防潮木地板、暖光营灯与地图桌）、加强筋金属油桶与无线电军械台；
   - 常规物资箱、前哨箱、紫光金库箱与【金边信标特级大金空投舱】全部采用独立写实材质与立体结构，无人机与石碑同步升级写实材质。
3. 阶梯式英语开箱体系（常规考单词，大金考词组与课本整句）：
   - 常规野外物资箱（6处）：按 [E] 输入【1个核心英文单词】即可开箱领物资（完美拼对 +10 分）；
   - 前哨补给箱（Tier 1）：【单词 + 重点词组】双关连破；
   - 竹林精密箱（Tier 2，史诗/大金）：【重点词组 + 教材短句】双关连破；
   - 山道特级空投箱（Tier 3，高爆传说大金）：【进阶词汇 + 重点词组 + 五上完整句子】三重破译！
   - 智能判分：自动忽略句末标点，支持缩写与全写通用（如 It's = It is, don't = do not），按 [Tab] 听标准发音。
4. 关键体验与 Bug 修复：
   - 修复背包满格时开箱丢物资与「替换最低物资」按钮失效问题，满包也能稳换传说大金；
   - 修复错词复盘面板点击单词朗读标准英文发音功能，以及新局宝箱盒盖复位。

【操作说明】
• WASD / 方向键：移动    • Shift：冲刺闪避    • 空格：跳跃
• 左键：射击             • 右键（按住）：全息镜瞄准
• R：换弹                • H：使用应急医疗包  • Q：朗读当前英文发音（破译界面按 Tab）
• E：开启常规单词箱 / 高阶密码箱 / 机关 / 启动撤离
• Esc：暂停 / 关闭面板   • F6：切换阴影画质   • F12：截图
