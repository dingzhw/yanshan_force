烟山行动 v0.8.5 · 英语单词搜撤游戏（大烟山 3 倍扩张 · 云顶演武坛 · 石卫 1.5s 潜行博弈 · 挂件零穿模）
更新日期：2026-11-21

双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility（核显/低配推荐）。「性能巡检.cmd」依次实测自由靶场纯训练、正式行动开箱撤离与四处核心场景帧时，报告写入 diagnostics/。

本版在 v0.8.4 基础上完成大烟山地图 3 倍扩张，并同步解决 v0.8.4 试玩提出的两项手感问题：
1. 「大烟山」3 倍可玩面积扩张与科学布局：围栏内可玩区域扩至 180m × 240m（43,200 m²，3.01×），6 座雾隐帮营地间距拉开至 62–176m 彻底去拥挤；「烟霞古洞」与「迷踪竹石阵」整体迁入西侧独立竹林幽谷（距所有营地 ≥64m）；北端山巅开辟直径 38m「云顶青石演武坛」（8 根盘龙青石柱 + 头顶零树冠），新增三孔青石拱桥、东岭茶亭与烟山摩崖石碑，小地图重校比例尺并增设中文地标简标（营/望/亭/洞/坛/撤）；
2. 「古洞循音石卫」无晕厥 1.5 秒潜行护核机制重构：彻底移除击核/累计伤害晕厥设定；击中胸口 0.30m 蓝核瞬间石卫立刻 X 型双臂护核并立即施展声波反击，玩家随即潜行静默（[C] 蹲伏 / [Z] 匍匐 / 静止不开火）持续 1.5 秒，石卫即放弃搜索回归巡逻并重新放开双臂露核；[G] 烟雾助消声脱搜，少羽 [V] 天生神力短暂震开双臂 1.0 秒（均不晕厥）；
3. 枪械 3D 挂件后移至瞄准镜侧下方枪体：全部 13 款成就挂件迁至瞄准镜左侧下方后上机匣枪体（精准夹在左手护木与右手握把之间），腰射、奔跑、开镜与换弹全程前后手零穿模；
4. 完整继承 v0.8.4 全物资双栏选择性确认拾取面板（入包 / 安全箱 / 蓝品筛选 / 现场丢弃腾位 / 未拾留箱）、默认游侠「少羽」[V] 天生神力、陈向导「烟山名望」随机委托与远距严格开镜狙词防骚扰。
