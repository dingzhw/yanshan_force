烟山行动 v0.9.5 · 英语单词搜撤游戏（主角少羽五官精雕与俯卧/低头重修 · 独立多阵营角色小传档案馆 · 宏大 3D 交互作战沙盘登录界面）
更新日期：2026-11-23

双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility（核显/低配推荐）。「性能巡检.cmd」依次实测自由靶场纯训练、正式行动开箱撤离与四处核心场景帧时，报告写入 diagnostics/。

本版承接 v0.9.4（55 骨全骨骼少羽、24 段动作库与物理飘带围巾），全面响应实机视觉与交互体验反馈，交付三大重磅升级：
1. 主角「游侠·少羽」精雕五官、零拧巴俯卧与 1P 低头重修：
   - 换装 Blender Studio CC0 精雕少年头模，配真实 3D 立体眼球/栗色瞳孔/白色眼神光，透过流线型超清琥珀护目镜（alpha=0.26）清晰可见双眸，360° 贴合发壳 + 16 束层次碎发彻底零秃斑，夹克/战术裤/战靴经 Catmull-Clark 细分平滑与线性色彩重校；
   - 以无万向节锁的世界空间四元数重写 Prone_Idle 与 Prone_Crawl，阿萨拉荒漠趴下双腿舒展自然，彻底根治拧巴扭曲；
   - 重修 1P 低头视角：隐藏腰部闭合帽并优化身位后移，低头直接看到平滑连贯的战术裤、护膝与战靴。
2. 独立多阵营「角色小传」全屏档案馆（14 张高清立绘 + 56 段渐进小记）：
   - 点击主菜单「📖 角色小传」进入独立全屏界面：第 1 页可在【烟山游侠小队(5)】、【雾隐帮与古洞秘境(4)】、【阿萨拉卫队(3)】、【哈夫克集团(2)】四大阵营间切换浏览高清立绘；
   - 点击任意人物进入独立人物专页：左侧装裱大幅高清立绘与语录，右侧展示 4 段渐进解锁的人物小记与实时进度条；
   - 游侠需多派遣出战、施展 [V] 技能、解锁成就与探访多战区逐步解锁，其余三大阵营分别通过清剿对应营地、破译密码箱、击败首领、突袭变电站、破译曼德尔砖与积累词汇量渐进解锁。
3. 宏大 3D 交互作战沙盘登录界面（左 1/5 导航栏 + 右 4/5 实时 3D 地形沙盘）：
   - 左侧 1/5 自上而下排布【📖 剧情模式】【🏔 烟山行动】【🏜 阿萨拉行动】三大入口及词库、角色小传、仓库、战备改装、奇珍图鉴；
   - 右侧 4/5 实时渲染立体 3D 作战沙盘：烟山行动展示江南青山溪谷与三大地标（中上【烟山基地】、左下【鲸塘中心小学（暂未开放）】、右中【诚庄村河港（暂未开放）】）；阿萨拉行动展示黄金沙漠峡谷、零号巨坝蓄水库与三大地标（中北【阿萨拉堡垒】、西南【巴克什古城外围（暂未开放）】、东南【哈夫克航天禁区（暂未开放）】）；进入对局自动暂停沙盘渲染，零局内帧率损耗。
