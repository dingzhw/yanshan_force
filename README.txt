烟山基地 v0.5.0 · 英语战术搜撤行动试玩
更新日期：2026-11-12

【快速开始】
• 标准启动：双击项目根目录「开始烟山试玩.cmd」（或独立包内「开始试玩.cmd」）。
• 低负载启动：双击「低负载启动.cmd」（游戏中按 F6 可随时切换实时阴影）。
• 单机离线直接运行，无需安装 Godot 或联网；完全兼容并保留旧版存档进度。

【v0.5.0 核心升级亮点】
1. 战斗与撤离平衡重构（告别无脑平推）：
   - 移除开局强制等待 35 秒靶场，直接进入【林间前哨】【山道拦截哨】【B · 竹林重兵阵地】三道防线；
   - 三大战术兵种协同守卫：突击词盾机甲、浮空绕翼侦察无人机、28 米红外激光重装狙击卫兵；
   - 索敌范围扩至 19–24 米，每小队最多 3 名敌人轮番火力压制；
   - 新增可充能纳米护盾（30 点，升级后 60 点）与 [H] 应急医疗包（+45 生命 / +25 护盾）；
   - 实战撤离门槛提升至【260 积分 + 至少攻克 1 处词兵前哨】，信标坚守读条 5 秒。
2. 高价值密码箱「拼写破译」与五级稀有度摸金：
   - 全图设三级密码箱，达标后按 [E] 启动破译终端，根据中文释义与骨架提示【准确输入英文单词】开箱；
   - 前 2 次内准确拼出享「完美破译」（+25 积分 + 大幅提升紫色史诗与金色传说大金爆率）；
   - 拼错 2 次自动展示完整拼写并朗读发音，对照输入即可稳拿物资，绝不卡关；
   - 新增普通/精良/稀有/史诗/传说·大金 5 级稀有度战利品、HUD 品质胶囊与营地大金藏品图鉴；
   - 军需商店扩充至 9 项实用改装（全息稳瞄镜、20发弹鼓、纳米护盾核心、急救扩容包等）。
3. 画面精修、音效手感与学习深度：
   - 重做第一人称步枪模型（移除突兀绿色圆柱假手臂，新增全息反射机瞄镜，右键开镜光学中心对齐）；
   - 精简为清爽四角战术 HUD，修复山坡巨石与终端悬空，赋予木棚/路牌/掩体真实木纹与金属质感；
   - 接入 Windows 原生离线标准英文语音（答题自动朗读，按 [Q] 随时重听，穿插电台听音辨词）；
   - 升级同词性/相近长度智能干扰项（防盲猜），持久化记录每词掌握度，五上数学与古诗扩充为各 6 题随机题池。

【操作说明】
• WASD / 方向键：移动    • Shift：冲刺闪避    • 空格：跳跃
• 左键：射击             • 右键（按住）：全息镜瞄准
• R：换弹                • H：使用应急医疗包  • Q：朗读当前英文发音
• E：开启密码箱 / 机关 / 拾取 / 启动撤离
• Esc：暂停 / 关闭面板   • F6：切换阴影画质   • F12：截图
