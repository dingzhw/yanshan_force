更新日期：2026-11-24

双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility（核显/低配推荐）。「性能巡检.cmd」依次实测自由靶场纯训练、正式行动开箱撤离与四处核心场景帧时，报告写入 diagnostics/。

本版基于 17 套 Poly Haven CC0 实景 1K PBR / 摄影测量资产与 Blender 5.3 管线，系统性根治双地图实机画质、穿模与角色解锁门控问题：
1. 阿萨拉沙漠多层次 PBR 质感革命与零穿模重修：
   - 8 通道沙漠 PBR 着色器（双尺度风纹细沙 + 砂砾路 + 古砂岩广场 + 陡坡三平面峡谷岩壁），全图建筑换装法线/粗糙度实景贴图；
   - 零号大坝两侧换装实心摄影测量巨岩悬崖，椰枣去发光黄蛋、金合欢重塑枝冠，全图 GPU 合批 231 处摄影测量荒漠灌木与散石；
   - 停机坪混凝土圆台新增 22° 倒角实心碰撞（彻底不陷脚），水泥厂 1 号集装箱移离钢梯零重叠，高台密码箱/应急箱/吉普/弹药堆全部平坦垫台零埋沙。
2. 烟山基地 240 处景物实体碰撞、植被/巨石摄影测量重构与场景精修：
   - 替换旧版“绿色草球”茶垄与“石板拼石头”巨石为立体龙井枝叶茶丛与 Poly Haven CC0 摄影测量苔藓花岗岩 + 48 株林间灌木；
   - 全图茶垄、苔石、石灯、青石凳、贴地倒木（消除悬空）与灌木配齐 240 处实心物理碰撞，彻底禁止穿模；
   - 升级烟山地表陡坡三平面苔岩着色，柔化溪岸苔草渐隐过渡，无缝闭合 360° 远山正中天际线接缝，精修营地红木绒布黄铜 3D 展台。
3. 雕塑级骨骼动画陈向导与雾隐帮战斗兵团：
   - 营地联络官「陈向导」换装带精雕五官双眸、宽檐探路帽、金围巾与望远镜的骨骼动画模型（npc_chen_guide.glb + 实体碰撞）；
   - 烟山雾隐突击兵与狙击卫换装江南斗笠飞檐盔、札甲肩铠与步枪/狙击枪骨骼动画模型（Idle_Aim / Walk_Patrol / Run_Advance）并消除枪管穿盾。
4. 严苛游侠人物名望解锁门控：
   - 修复旧版宽松旁路导致老档全部游侠自动解锁的问题；初始仅解锁主角「少羽」，其余 4 位游侠解锁前严格以“？”加密立绘隐藏（陈向导需通关序章或 ≥1 项委托；林听风 300 / 苏青禾 600 / 竹影 900 名望解锁）。
