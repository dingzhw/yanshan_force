烟山基地 v0.5.5 · 英语战术搜撤行动试玩
更新日期：2026-11-13

【快速开始】
• 标准启动：双击项目根目录「开始烟山试玩.cmd」（或独立包内「开始试玩.cmd」）。
• 低负载启动：双击「低负载启动.cmd」（游戏中按 F6 可随时切换实时阴影）。
• 单机离线直接运行，无需安装 Godot 或联网；完全兼容并保留旧版存档进度。

【v0.5.5 重点升级（山间溪流 · 动植物生态 · 奇花异草 · 围栏稻田远景）】
• 活水山溪与 3 座山溪桥：蜿蜒溪流自北向南淌过烟山，营地中北 3 座带缓坡引桥木桥可顺畅通行，水面点缀睡莲与溪石；
• 4 种动态小动物（24 只）：林间小野兔与小松鼠靠近或听枪声受惊逃跑，溪中游动小鱼与石岸横行螃蟹，开枪或挥刀命中化作微光消散，近距发现解锁英文读音；
• 坡野奇花异草与 8 处 `[E]` 辨识点：240+ 株批渲染野花蘑菇与自建夜光幽兰/朱果奇蕨，`[E]` 辨识学英文名称例句并回血加分；
• 山腰木栅栏与 360° 稻田远景：实木护栏围合山区边界替代空气墙，站在观景栏可俯瞰栏外 3D 梯田稻田、白墙黑瓦农舍与青岚远山环幕。

【操作说明】
• WASD / 方向键：移动    • Shift：冲刺闪避    • 空格：跳跃
• 1 / 2 / 滚轮：切枪切刀 • V：快刀近战        • R：换弹
• 左键：射击 / 挥刀      • 右键（按住）：瞄准（含 2 倍棱镜缩放）
• H：应急医疗包          • G：烟雾/EMP 手雷   • T：肾上腺素能量饮
• Q：朗读当前英文发音    • Tab（破译界面）：播放目标词句发音
• E：辨识奇花异草 / 开常规或密码箱 / 线报板 / 侦察电台 / 撤离
• Esc：暂停 / 关闭面板   • F6：切换阴影画质   • F12：截图
