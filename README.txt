更新日期：2026-11-21

双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility（核显/低配推荐）。「性能巡检.cmd」依次实测自由靶场纯训练、正式行动开箱撤离与四处核心场景帧时，报告写入 diagnostics/。

本版在 v0.8.3 基础上完成三项深度战斗交互与搜刮体验升级：
1. 枪械 3D 挂件左侧外显重构：13 款成就 3D 挂件迁至步枪朝向镜头的左前外侧导轨黄铜悬臂并放大至 1.45×，带防穿模摆动限位，腰射、奔跑、换弹与右键开镜（ADS）下均清晰可见且零遮挡准星与左手；
2. 「古洞循音石卫」Blender 4.5 分件重塑与双臂护核博弈：拆分为独立可动双臂巨型青石盾 + 主体 + 听音冠，胸口蓝核缩小至紧凑 0.30m；受击立刻 X 型交叉合拢双臂护住胸核（正面偏折音效 + 极低擦伤），唯有诱其大步追击或用 [G] 烟雾致盲 / 少羽 [V] 天生神力震晕 / 累计失衡破防时才张臂露核爆发斩杀，击败后洞内实体掉落可交互战利品包；
3. 全物资双栏选择性确认拾取面板：密码箱、补给箱、小队/首领/石卫掉落包、14 处隐蔽秘藏、探索奖励箱及地面/石案单件散落珍宝 100% 统一弹出双栏确认拾取面板——左栏支持逐件 [拾取入包] / [🔒 存安全箱] 与放大镜扫描快进，右栏实时整理「🔒 加密安全箱（2 格）」与「🎒 随身背包（支持现场 [丢弃腾位]）」，底部支持一键 [◆ 只拾取蓝品及以上] / [✓ 全部拾取] / [离开（剩余留箱）]，未拾取物品保留在原处可回头再拿；
4. 完整继承 v0.8.3 默认游侠「少羽」与 [V]「天生神力」、陈向导「烟山名望」随机委托、图鉴「👤 人物小记」与远距严格开镜狙词防骚扰机制。
