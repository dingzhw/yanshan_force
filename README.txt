烟山基地 v0.8.0 · 英语单词搜撤游戏（摸金经济重塑 · 64 件博物藏品 · 收藏库与安全箱）
更新日期：2026-11-20

双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility。「性能巡检.cmd」记录实际档位、首屏和普通行动两处交战帧时。
本版升级 7 级稀有度（增设「珍品·小金」），按 v0.7.2 博物标准扩充至 64 件独立 PBR 3D 藏品、64 张影棚 2D 图标与 279 条离线美式自然女声语音；新增营地「我的仓库」（单件出售、🔒锁存大金/大红、一键售杂物、4 槽营地 3D 展台）与局内 2 格加密安全箱（阵亡/超时也能带回）；校准普通/机密爆率梯度，取消露天大路刷大红与箱体品质剧透，新增 14 处草丛/花丛/桥墩隐蔽秘藏，并关闭生灵与花草头顶常驻文字还山水一片清爽。
窗口内按 F6 可切换当前渲染器的画质。玩法、按键、间隔复习、存档迁移和巡检说明见下列文件。
