烟山行动 v0.9.3 · 英语单词搜撤游戏（63 条全阵营离线中文配音 · 15/20 分钟三营节奏 · 极简现代战术 HUD · 主角 3D 实体与 1P/3P 自由切换）
更新日期：2026-11-22

双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility（核显/低配推荐）。「性能巡检.cmd」依次实测自由靶场纯训练、正式行动开箱撤离与四处核心场景帧时，报告写入 diagnostics/。

本版在 v0.9.2 双战区完全体基础上，全面升级声画沉浸、极简现代 HUD、对局节奏与主角实体双视角：
1. 63 条本地离线中文阵营与首领配音（game/assets/voice_cn/*.ogg）：
   - 覆盖阿萨拉士兵（8 条：“来！咱俩练练！”等）、赤枭·赛伊德（10 条）、阿萨拉军阀·雷斯（10 条）、哈夫克特勤（8 条带电台滤波）及烟山村雾隐帮全系（雾隐词兵 8 / 铁面词卫 7 / 玄铁词尊 7 / 古洞循音石卫 5 带溶洞回声）；
   - 靠近敌营或交战/放技时随机播放并弹出左上角紧凑电台字幕；英语单词读音绝对优先自动压低敌方喊话，可在「⚙ 设置」独立调音量与试听；
2. 对局时长与扫荡营地规则升级：
   - 普通行动限时 15 分钟（900s），机密行动限时 20 分钟（1200s），双模式撤离所需攻克营地统一升至 3 座；
3. 《三角洲行动》风格极简现代化战术 HUD：
   - 顶部中央仅留通透英语学习条（中文提示 + [🔊 X] + 细倒计时条），左上单行图标状态条，左下矢量姿态剪影（站/蹲/趴/探头 + 1P/3P 标）+ 护盾/血条 + 紧凑背包微标，右下大字号弹药 + 枪/刀剪影 + 4 格战术图标（[H/G/T/V]）；
   - 移除底部长按键提示条大幅释放正面视野，随时按 [F1] 展开/收起完整战况与按键表；
4. 主角「少羽」3D 实体身体 + [P]/[F5] 1P/3P 无缝切换：
   - Blender 4.5 精建全身可动游侠模型（苍青冲锋衣/赤金领巾/战术背包/护目镜/同步持枪涂装与切刀背枪），完整走跑跳蹲趴爬行探头/挥刀/[V]重拳动画；
   - 1P 下低头可见真实双腿战靴；按 [P]/[F5] 秒切 3P 越肩防穿墙视角，内置零视差精准准星射击与装配红点/2倍镜右键自动无缝切镜。
