烟山行动 v0.8.3 · 英语单词搜撤游戏（游侠「少羽」与 [V] 技能「天生神力」 · 烟山名望委托 · 人物小记角色卡）
更新日期：2026-11-21

双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility（核显/低配推荐）。「性能巡检.cmd」依次实测自由靶场纯训练、正式行动开箱撤离与四处核心场景帧时，报告写入 diagnostics/。

本版在 v0.8.2_dev2 基础上正式搭起可扩展【游侠】主角与名望世界观框架：
1. 默认游侠「少羽」与 [V] 技能「天生神力」：按 [V] 挥出重拳砸地，以 3D 金色震地冲击环将周围 7.8m 内雾隐帮词兵震倒在地 1.5 秒（停火暴露词盾，对 Boss 与古洞循音石卫触发硬直打断），冷却 30 秒，右下角常驻专属技能充能条；
2. 键位解耦：[V] 专属归属游侠主动技能；匕首近战保留 [2] 切刀 + 左键挥砍，并新增鼠标中键快捷近战挥刀；
3. 营地联络员「陈向导」随机委托与「烟山名望」：正式行动中按 [F] 找营地帐篷旁「陈向导」查看或更换每局随机委托，完成后即刻结算烟山名望与行动币，并累计游侠段位；
4. 奇珍图鉴新增「👤 人物小记」页签：集中展示游侠「少羽」、陈向导、雾隐帮与三大 Boss 共 8 张角色卡，并预告 v0.9.0 名望招募游侠（林听风 / 苏青禾 / 竹影）；
5. 完整继承 v0.8.2_dev2 全部六项数值与体验优化（近战 5/10 刀、定量弹药稀缺、720 HP 红圈 Boss、620/960 HP 古洞石卫、复测光标连打、换词自动读音与山坡靶牌修复）。
