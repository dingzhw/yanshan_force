双击项目根目录「开始烟山试玩.cmd」，或独立包里的「开始试玩.cmd」。
「低负载启动.cmd」使用 GL Compatibility（核显/低配推荐）。「性能巡检.cmd」依次实测自由靶场纯训练、正式行动开箱撤离与四处核心场景帧时，报告写入 diagnostics/。

本版承接 v0.9.3（全阵营 63 条中文配音、15/20 分钟三营节奏、极简现代 HUD 与 1P/3P 切换），专项针对主角「游侠·少羽」进行端游级 3D 模型、骨骼动画与据枪手感全面重塑：
1. 「游侠·少羽」方案 B 全新英雄外形（55 骨平滑蒙皮，9,897 面，1.75m 少年比例）：
   - 引入 CC0 精品开源人体/战术拓扑底座并经 Blender 4.5 精雕平滑：乌黑微扬短碎发 + 戴眼半透明琥珀战术护目镜 + 单耳耳麦；
   - 朱砂红游侠围巾 + 4 节独立物理蒙皮飘带（Godot 4.7.2 原生 SpringBoneSimulator3D 驱动，奔跑转向实时迎风飘动）；
   - 青黛墨竹卷袖短款夹克（前臂缠带 + 左肩鎏金云纹臂章）+ 紧凑暗炭灰三联弹匣 MOLLE 胸挂与迷你对讲机 + 贴身流线型山野小背囊 + 古铜加固指虎半指手套 + 修身炭灰多袋战术裤/护膝/越野战靴；
2. 24 段真实骨骼动作库 + Godot 4.7.2 上下半身融合动画树：
   - 世界空间四元数无损重定向 Quaternius UAL + KayKit（CC0）真实人形步态与战斗动作（站姿错步战斗架势、8 向走跑冲刺、侧移、后退、蹲走、俯卧爬行、起跳落地、换弹、匕首连斩）；
   - AimSpineModifier 实时将抬头/低头与 Q/E 探头流畅分摊至脊柱/胸腔/头部，彻底告别木偶感；
3. 零怪异精准双手据枪 & 专属 [V]「天生神力」背枪重拳：
   - 以 YS-04 卡宾枪实尺寸求解解析 2-Bone IK 与五指局部握持弯曲，枪托稳抵右肩窝、右手紧扣握把、左手托稳护木；
   - 切刀或发动 [V] 重拳震地时，YS-04 步枪自动斜背挂至背后 Weapon_Back，古铜指虎右拳下砸震地，彻底消除步枪指天；1P 低头同样可见真实平滑蒙皮双腿与战靴。
