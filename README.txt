烟山基地 v0.6.0 · 英语战术搜撤行动试玩
更新日期：2026-11-13

【快速开始】
• 标准启动：双击项目根目录「开始烟山试玩.cmd」（或独立包内「开始试玩.cmd」）。
• 低负载启动：双击「低负载启动.cmd」（游戏中按 F6 可随时切换实时阴影）。
• 单机离线直接运行，无需安装 Godot 或联网；完全兼容并保留旧版存档进度。

【v0.6.0 重点升级（方案 A「古今交织」· 江南地标重塑，完整保留前序生态与玩法）】
• 江南飞檐重檐「望稻亭」：坐落东岭高台、木牌匾题字「望稻亭」，内置美人靠长凳与石桌茶盏，推栏南望诚庄阡陌稻田与农舍村落全景；
• 青石单孔拱桥与古道界碑：溪谷中游升级青石单孔拱桥与护岸挡墙，桥畔立「烟山古境」阴刻青石界碑，步入不卡跳即可顺畅过溪；
• 传统「烟山诗碑亭」与「百年古樟 · 土地石龛」：西岭原方尖碑重塑为飞檐四柱古诗碑亭（靠近可按 [E] 研读《烟山诗》），北麓百岁古樟系红绸遮荫乡野土地石龛（夜间与低负载自动适配烛火）；
• 青石板山径与生态融合：沿主山径铺设贴合坡度起伏的青石板古道，并与活水溪流、林间鸟兽花草及战术阵地自然交织。

【操作说明】
• WASD / 方向键：移动    • Shift：冲刺闪避    • 空格：跳跃
• 1 / 2 / 滚轮：切枪切刀 • V：快刀近战        • R：换弹
• 左键：射击 / 挥刀      • 右键（按住）：瞄准（含 2 倍棱镜缩放）
• H：应急医疗包          • G：烟雾/EMP 手雷   • T：肾上腺素能量饮
• Q：朗读当前英文发音    • Tab（破译界面）：播放目标词句发音
• E：辨识奇花异草 / 开常规或密码箱 / 线报板 / 侦察电台 / 撤离
• Esc：暂停 / 关闭面板   • F6：切换阴影画质   • F12：截图
