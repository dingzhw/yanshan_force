# 烟山行动 · v0.9.5 版本规划与技术实现方案

日期：2026-11-23  
基线：`v0.9.4`（`a0d7989`，55 骨全骨骼少羽 + 24 段真实骨骼动作库 + SpringBone 围巾物理）

## 一、核心目标与问题拆解

围绕实机截图反馈与产品演进方向，`v0.9.5` 确立三大攻坚支柱：

1. **主角「游侠·少羽」建模精雕、零拧巴俯卧与 1P 低头重修**：
   - 解决 `v0.9.4` 面部偏粗糙、无精细五官的观感问题：引入 CC0 Blender Studio Human Base Meshes v1.4.1（`GEO-body_male_stylized`）精细雕塑头模，精修东亚健朗少年比例与鼻梁，内置真实 3D 立体眼眶/巩膜/栗色虹膜/黑瞳/高光眼神光与上睫毛线，配合流线型超清琥珀护目镜（`alpha=0.26`）让双眸清澈有神；基于真实颅骨曲面挤出 360° 贴合发壳 + 16 束层次碎发彻底消除后脑秃斑；全套夹克、战术工装裤与越野战靴执行 Catmull-Clark 细分平滑（`level=1`）并引入线性 sRGB 色彩校准（总计 `24,054` 顶点 / `24,667` 面 / `10` 分层网格）；
   - 根治俯卧双腿拧巴问题：定位 `v0.9.4` `Euler((88°, 0, 12°), 'XYZ')` 触发 `90°` 万向节锁导致小腿与靴子拧麻花，改用 `Quaternion((0,0,1), splay) @ Quaternion((1,0,0), pitch)` 世界空间四元数顺序合成重做 `Prone_Idle` 与交替 `Prone_Crawl`；
   - 重修 1P 低头视角：为 3P 增设闭合深青腰缘、战术腰带与古铜扣（`Shaoyu_LowerWaist`），1P 下仅保留平滑 `Shaoyu_LowerLegs` 与 `Shaoyu_LowerBoots` 并将身位调至 `z = 0.27/0.30/0.34m`，低头直接落向自然连贯的裤腿、护膝与战靴（彻底告别旧版怪异断层与腰帽遮挡），同步修复 `TwoBoneIK3D` 极向共线警告。

2. **独立全屏多阵营「角色小传」档案馆（`game/scripts/lore_codex_ui.gd`）**：
   - 双页独立全屏界面：
     - **第 1 页（阵营总览）**：四大阵营自由切换——**🌿 烟山游侠小队（5人）**、**⚔ 雾隐帮与古洞秘境（4人）**、**🏜 阿萨拉卫队（3人）**、**🛰 哈夫克集团（2人）**，共配 **14 张高清风格化 3D 人物立绘（`game/assets/portraits/*.png`，`512×640`）**；
     - **第 2 页（独立人物专页）**：左侧装裱大幅立绘、中英文代号、经典语录与战地特征；右侧滚动展示 **每人 4 段渐进解锁人物小记（全馆 56 段）**，锁定章节清晰展示解锁条件与实时进度条；
   - **差异化渐进解锁体系（`rules.gd` `profile.lore_stats`）**：
     - 游侠阵营：随派遣少羽出战局数、施展 `[V]` 天生神力次数、解锁成就数、探访多战区场景（序章/烟山/古洞/阿萨拉）、完成委托与烟山名望逐段解封；
     - 雾隐帮 / 阿萨拉 / 哈夫克阵营：分别随清剿对应战区营地、无错破译密码箱、击败铁面词卫/玄铁词尊/古洞石卫/赛伊德/雷斯、突袭东区变电站、破译曼德尔加密砖、收集战区奇珍与词汇掌握量逐层解封，并自动兼容老存档追溯已达成里程碑。

3. **宏大 3D 交互作战沙盘登录界面（`game/scripts/war_map_3d.gd` + `main.gd`）**：
   - 采用现代特战指挥台 **左侧 1/5 命令栏（268px） + 右侧 4/5 实时 3D 立体沙盘（1012×720）**，独立 `SubViewport`（`own_world_3d = true`）进战自动挂起，确保对局内 0 FPS 额外开销；
   - 左侧自上而下排布三大主入口：**📖 剧情模式**、**🏔 烟山行动**、**🏜 阿萨拉行动**，下接词库范围、今日复测、角色小传、仓库/改装/图鉴与名望货币状态；
   - **烟山行动 3D 沙盘**：实时渲染青绿江南山地、梯田、溪河、道路与浮云——中上高地 **`【烟山基地】`**（望稻红亭 + 岗楼 + 绿光信标，可点选出击）、左下平地 **`【鲸塘中心小学（暂未开放）】`**（微缩教学楼 + 旗杆 + 红色跑道操场）、右中河湾 **`【诚庄村河港（暂未开放）】`**（白墙黛瓦村落 + 石拱桥 + 木码头小舟）；
   - **阿萨拉行动 3D 沙盘**：实时渲染黄金沙漠、红岩峡谷、碧蓝大坝蓄水库与棕榈绿洲——中北峡谷咽喉 **`【阿萨拉堡垒】`**（零号巨坝 + 巴别双塔 + 行政堡垒，未解锁时亦支持 3D 预览与一键跳转设置试玩开关）、西南绿洲 **`【巴克什古城外围（暂未开放）】`**、东南高原 **`【哈夫克航天禁区（暂未开放）】`**；
   - **剧情模式 3D 暖阳山谷**：展示第一章《烟山初行·单人序章》（可立即出击）与第二章预告。
