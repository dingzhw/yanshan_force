# 烟山基地 v0.8.4 阶段计划

- **日期**：2026-11-21
- **开发基线**：`v0.8.3`（`c8d0661`，工作区干净，源码 9 套件 504/504 PASS）
- **目标与范围**：落实 `2026年11月21日-v0.8.3试玩.md` 中第 2、4、5 项反馈及已拍板规划：
  1. **枪械挂件左侧外显重构（`game/scripts/weapon.gd`）**：将 13 款成就挂件由护木下方改挂至步枪朝向镜头的左前外侧战术挂耳，本体适度放大（`~1.45×`）并增强材质层次与防穿模限位，确保腰射、战斗、跑动、开镜均醒目可见且不遮挡准星。
  2. **「古洞循音石卫」Blender 4.5 分件重塑与双臂护核博弈（`tools/build_v082_bosses.py` + `game/scripts/cave_warden.gd` + `tools/generate_sfx.py`）**：
     - 将 `cave_warden` 拆分为 `warden_body`、`arm_left_pivot`（厚重青石臂盾）、`arm_right_pivot`（厚重青石臂盾）与 `head_crest` 四个独立可驱动节点并保留多材质 PBR 质感；
     - 胸口发光蓝核碰撞半径由 `0.56m` 收紧至 **`0.30m`**（晶核外观同步精悍化）；
     - 实装「受击即双臂合拢护核（正面拦截弹开音效 `warden_shield_deflect.wav`，仅 `8–10` 擦伤）↔ 主动追击/被 `[G]` 烟雾或 `[V]` 天生神力或失衡破防时双臂大张露核（`55/45` 暴击、硬直 `85/70`）」的攻防拉扯循环；击败石卫掉落实体秘宝包走统一确认拾取面板。
  3. **全物资选择性确认拾取面板（`game/scripts/loot_container_ui.gd` + `rules.gd` + `cipher_terminal.gd` + `world_loot.gd` + `exploration.gd`）**：
     - 覆盖密码箱、野外补给箱、小队/首领/石卫掉落包、14 处隐蔽鸟窝与太湖石缝、10 处地面/石案单件散落物资以及探索解谜奖励容器（寒潭茶灶、北脊空投、封存补给等）；
     - 双栏布局：左栏展示容器物资（2D 影棚图标、稀有度色条、双语名、品相与估值，支持放大镜逐格鉴定与单件 `[拾取]` / `[存安全箱]`），右栏实时展示战术背包与 2 格加密安全箱（支持一键 `[丢弃腾位]` 与安全箱互换），底栏提供 `[只拾取蓝品及以上]` / `[全部拾取]` / `[离开（剩余留箱）]`，未拿走物品保留原容器可随时复开。
- **延后事项**：
  - 烟山地图 3 倍扩张（方案 A `180×240m`）与云顶演武坛归属 **`v0.8.5`**；
  - 机密「玄铁词尊」多招式重做与终极技「天地万象」归属 **`v0.8.6`**。
