# 烟山基地 v0.7.1 验收记录（语音热修版）

G 团队 · 2026 年 11 月 20 日 · Windows 本地验收包

本版基于 `v0.7.0` 本地验收包（Git 提交基线 `v0.6.7 / 4c3931d`）发布紧急热修 `v0.7.1`，根治此前导出包拷贝至家用 Windows 11 电脑后所有英文单词不发音的阻断性 Bug。本机独立 PCK 400/400 回归、22/22 成品资源校验及**真实导出 `YanshanBase.exe`** 三档启动与语音实测均已通过；**5700G / Vega 8 实机性能、学生普通行动首局（5–8 分钟）与次日脱机回忆三项仍未开展（标 `false`）**，请先拷至目标电脑确认听音并同步完成首轮家庭实测。[阶段计划](v0.7.1-阶段计划.md) · [v0.7.0 验收记录](v0.7.0-验收记录.md)

## 一、静音 Bug 根因与修复内容

- **根因 1（导出硬 Bug）**：`game/project.godot` 此前未设置 `audio/general/text_to_speech=true`。Godot 4 默认值为 `false`，编辑器下仍可列出声音，但独立导出的 Windows 成品 `YanshanBase.exe` 会关闭系统 TTS 子系统，导致所有机器均无声。本版已在 `game/project.godot` 显式开启 `[audio] general/text_to_speech=true`。
- **根因 2（跨电脑无英文语音包）**：简体中文版 Windows 11 默认往往仅含中文语音，纯依赖 `DisplayServer.tts_get_voices_for_language("en")` 换机即哑。本版新增 `tools/build_voice_pack.py`，为全游戏去重后的 **247 条**英文朗读文本（175 课本词 + 16 教材句 + 32 藏品英文 + 生灵与探索语料）预先合成美式自然女声（`en-US-JennyNeural`，语速 `-5%`，单声道 24kHz OGG Vorbis，共 `3.09 MB`），落盘至 `game/assets/voice/v_*.ogg` 与 `game/data/learning/voice_manifest.json` 并随 PCK 一体导出。
- **双通道零依赖播音架构**：`main.gd` 新增 `normalize_voice_key()`、`has_english_voice()`、`load_voice_stream()` 与独立 `voice_player: AudioStreamPlayer`（音量 `-1.5 dB`，切题即止防叠音）。播音优先走内置离线 `.ogg`，仅在未来新词未命中清单时回退系统英文 TTS；`combat.gd`、`cipher_terminal.gd` 与 `main.gd` 的听音题、`[X]` 重听与开箱 `[Tab]` 发音已全部解耦对 `tts_voice_id != ""` 的强依赖。
- **素材合规说明（规则八·2）**：`game/THIRD_PARTY.txt` 与 `voice_manifest.json` 已如实注明该批离线语音由本地 `edge-tts` 生成、仅供个人/家庭离线教学试玩使用；未来对外公开分发前可通过 `tools/build_voice_pack.py` 一键替换为开放许可离线 TTS 或自录音频。

## 二、真实导出成品 EXE 与独立 PCK 验证

测试机：AMD Ryzen 9 5900X + AMD Radeon RX 6600，Windows 11，Godot 4.7.2，1280×720。所有测试均直接跑最终导出的 `playtest/windows-v0.7.1/YanshanBase.exe` 与 `YanshanBase.pck`。

### 1. 语音与回归核验

- **独立 PCK 全量回归**：9 组共 **400 / 400 项全部通过**（`learning 39`、`combat 61`、`economy 32`、`smoke 33`、`movement 27`、`navigation 13`、`physics 18`、`challenges 12`、`slice 165`）。新增 3 项学习语音断言确认：`audio/general/text_to_speech == true`、175 词 + 16 句 + 32 藏品 100% 命中离线清单、强制清空 `tts_voice_id` 时 `has_english_voice()` 与 `speak_english("put ... in order")` 仍经 `"ogg"` 通道成功加载有效 `AudioStream`。
- **成品资源检查（`tools/verify_packaged.gd`）**：**22 / 22 通过**，逐条核验 `voice_manifest.json` 全部 247 个 `.ogg` 存在于独立 PCK 且样本流可解码。
- **真实导出 `YanshanBase.exe` 启动报告实测**：Forward+ 标准、Forward+ 低档、GL Compatibility 三档实跑成品 EXE，均输出 `tts_setting_enabled: true`、`tts_voice_ready: true`、`voice_pack_count: 247`、`voice_sample_playable: true`。
