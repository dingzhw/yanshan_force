烟山基地 · v0.8.5 试玩说明
更新日期：2026-11-21

【启动方式】
- 项目根目录双击「开始烟山试玩.cmd」；或独立分发包内双击「开始试玩.cmd」。
- 核显 / 低配笔记本优先双击「低负载启动.cmd」（GL Compatibility），局内按 [F6] 可随时开关阴影。
- 查看完整近期与中长期开发规划：docs/游戏发展路线图.md

【v0.8.5 新增核心内容（大烟山 3 倍面积扩张 · 云顶青石演武坛 · 石卫 1.5s 潜行机制重构 · 挂件后移零穿模）】
1. 「大烟山」3 倍可玩面积扩张与营地科学疏散：
   - 围栏内可玩范围由 104m × 138m 扩展至 180m × 240m（43,200 m²，约 3.01 倍），6 座雾隐帮营地间距拉开至 62–176m，彻底告别营地拥挤与视野/仇恨串联。
   - 「烟霞古洞」与「迷踪竹石阵」整体迁入西侧独立竹林幽谷（距所有战斗营地均 ≥64m），古洞听声探宝完全不受外围营地交火干扰。
   - 北端山巅开辟直径 38m 的开阔「云顶青石演武坛」（平整青石广场 + 8 根盘龙青石柱 + 头顶零树冠遮挡），既可作为 B 区总坛决战地，也为下一版玄铁词尊与「天地万象」大招预留宏大舞台。
   - 同步新增 Blender 4.5 江南人文地标：中溪三孔青石拱桥、东岭茶亭、烟山摩崖石碑与云顶盘龙柱阵；小地图按大烟山比例尺重校并新增中文地标简标（营 / 望 / 亭 / 洞 / 坛 / 撤）。
2. 「古洞循音石卫」受击护核与 1.5 秒潜行脱搜机制重构（响应 v0.8.4 试玩反馈）：
   - 彻底取消“击中核心 / 累计受创触发长晕厥”设定。
   - 击中石卫胸口蓝核瞬间：石卫会**立刻双臂交叉护住核心**，并**立即朝玩家施展声波攻击反击**（护核期间正面射击护盾仅触发石盾偏折低擦伤）。
   - **1.5 秒潜行静默脱搜**：玩家随即按下 [C] 蹲伏或 [Z] 匍匐进入潜行静默（静止/轻步且不开枪）持续 **1.5 秒**后，石卫就会放弃搜索、回归巡逻并重新放开双臂，再度暴露胸口 0.30m 蓝核——形成“狙核 → 护核声波反击 → 潜行静默 1.5s 脱搜 → 再次开臂破核”的真听声潜行博弈！
   - [G] 烟雾弹可掩护消声帮助更快脱搜（不再长晕）；少羽 [V] 天生神力可短暂震开石卫双臂 1.0 秒创造补枪窗（同样不晕厥）。
3. 枪械 3D 挂件后移至瞄准镜侧下方枪体（响应 v0.8.4 试玩反馈）：
   - 将全部 13 款成就 3D 挂件整体后移至瞄准镜左侧下方的后上机匣枪体（精准落在左手护木与右手握把之间的空档），并收紧黄铜挂耳，确保腰射、奔跑、开镜（ADS）与换弹动作下前后双手均彻底零穿模。

【同时完整继承 v0.8.4 核心特性】
- 全物资（密码箱 / 补给箱 / 掉落包 / 14 处隐蔽秘藏 / 探索奖励 / 地面单件散落珍宝）统一双栏选择性确认拾取面板（逐件入包、直存安全箱、只拾取蓝品及以上、满包现场丢弃腾位、未拾留箱复开）；
- 默认游侠「少羽」[V]「天生神力」震倒词兵 1.5 秒（30 秒冷却）、陈向导随机委托「烟山名望」、图鉴「👤 人物小记」与远距严格右键开镜狙词防骚扰。
