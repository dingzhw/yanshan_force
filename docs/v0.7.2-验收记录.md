## 一、32 件藏品独立建模与影棚 2D 图标

- **32 件一一对应独立美术 ID**：在 `game/scripts/rules.gd` 保留全部中文品名与英文名不变（兼容旧档收集进度与 247 条离线语音）的前提下，拆分原先共用的 6 组图标键（`rangefinder` / `nvg_lens` / `jade_piece` / `silver_lock` / `censer` / `jade_bi`），实现 32 件藏品 100% 独立建模与独立图标；`loot_ui.gd` 内置 `TITLE_TO_ART_ID` 与 `LEGACY_ICON_ALIAS`，旧档仓库藏品自动升级显示新美术。
- **Blender 4.5 独立多材质 PBR 3D 藏品库**：通过 `tools/generate_v072_textures.py`（15 张本地自绘文物/战术贴图，含山水折扇、岩画残拓、竖排墨书竹简、指北针表盘、青瓷开片、古玉云纹、长命百岁银锁、紫芝轮纹、黑匣子与双语终端屏等）与 `tools/build_v072_collectibles.py`，在 Blender 4.5.3 LTS 中导出单包 `game/assets/slice/v072_collectibles.glb`（4.60 MB，32 个命名网格 `loot_<art_id>`，覆盖 T1–T6 全部藏品；彻底替换通用方块与裸圆环，如 `诚庄先民双龙玉璧` 改为扁平双缘玉璧 + 双龙戏珠浮雕 + 紫檀插屏座，`越窑秘色青瓷盏` 为 10 瓣葵口莲瓣盏 + 紫檀托盘，`烟山之心·赤金龙印` 为盘龙衔红宝印钮 + 回纹金座）。所有资产为本地原创/程序化生成（CC0 / Original Project），已记入 `game/THIRD_PARTY.txt`。
- **32 张同源 Cycles 256×256 影棚透明 2D 图标**：在 Blender 4.5 Cycles 影棚三点布光下由每件 3D 模型同源渲染输出至 `game/assets/icons/loot/<art_id>.png`（共 1.59 MB），确保背包、出大红/大金弹窗、开箱揭晓与「烟山奇珍图鉴」所见即所得；初版审图发现玉璧/银锁/太湖石/春茶高光略过曝、虎符偏圆润、琥珀偏亮黄后已完成第二轮精修与复拍。[32 件图标总览表](v072-review/contact_sheet_32_icons.png) · [建模指标](slice-v072-collectibles.json)

## 二、360° 交互式 3D 检视台与 720p 游戏内实拍

- `game/scripts/loot_ui.gd` 升级 `[I]` 3D 宝物检视台：新增独立 `WorldEnvironment` 影棚环境光 + 暖主光/冷辅光/稀有度轮廓光、紫檀丝绒展台底座，支持**左键拖拽 360° 自由旋转（偏航 + 俯仰）、滚轮缩放细看、暂停/恢复自转与重置视角**；露天石案战利品（`world_loot.gd`）同步切换至 32 件独立 PBR 模型。
- 以下 6 组 720p 截图均直接基于独立成品 PCK 在 Godot 4.7.2 Forward+ 实拍核验：
  - [烟山奇珍图鉴](v072-review/compendium-v072.png)：已解锁大红/大金珍宝呈现清晰影棚图标，未解锁条目以真实模型深色剪影配 `?` 提示；*客观记录*：图鉴卡片底行有 3 条较长中文描述在按钮左侧略显贴边截断（点进 3D 检视右侧档案区可完整浏览），列为后续微调项。
  - [随身摸金背包](v072-review/backpack-v072.png)：8 格混装 T2–T6 藏品图标轮廓与配色一目了然，读音/3D 检视/丢弃按钮排布整齐无重叠。
  - 3D 检视特写：[诚庄先民双龙玉璧](v072-review/inspect-jade-bi.png) · [烟山之心·赤金龙印](v072-review/inspect-seal.png) · [越窑秘色青瓷盏](v072-review/inspect-celadon.png) · [军用黑匣子](v072-review/inspect-blackbox.png)。经二次调优默认视距（`1.62`）与展品倍率（`1.82`）后，高件珍宝四周留白舒展，底座与雕工完整露出。
