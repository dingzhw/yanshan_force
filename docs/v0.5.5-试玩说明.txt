【快速启动】
• 标准画质启动：双击「开始试玩.cmd」（或项目根目录「开始烟山试玩.cmd」）。

• 全程单机离线运行，无需安装 Godot 或联网；自动沿用并兼容旧版存档进度。

【v0.5.5 核心升级（活水山溪 · 林间生灵 · 奇花异草 · 木栅栏与稻田远景）】
1. 贯穿山野的山间溪流与 3 座可通行木桥：
   - 北麓山泉汇流成蜿蜒溪流（`MountainStreamWater`）自北向南淌过烟山，水面随山势阶梯稳降并带波纹光泽；
   - 在营地东侧（z=7.0）、中路崖桥（z=-24.0）与北哨东坡（z=-46.5）修建 3 座带缓坡引桥与木栏杆的山溪木桥，步兵可顺畅走过桥面，溪内布置水莲与踏水溪石；小地图同步标出蓝色溪流与木桥标记。
2. 4 种动态可交互动物生态（`wildlife.gd`）：
   - **小野兔（Little Rabbit ×6）与小松鼠（Red Squirrel ×5）**：林间漫游觅食，听见枪声或有人靠近时立刻转身跃跳逃跑；
   - **溪流小鱼（Brook Fish ×8）与溪石螃蟹（River Crab ×5）**：小鱼在澄澈溪水中摆尾游弋，螃蟹沿溪畔卵石横行；
   - **近距离发现与击灭消散**：走近惊动每种动物即可首次解锁英文物种发现（`+5` 分 + 标准英文语音），使用卡宾枪或 `[2]/[V]` 匕首击中动物后会化作林间微光在 `~1.85` 秒后消失（并于约 `26` 秒后重新在远处刷新）。
3. 满坡繁花与 8 处奇花异草英文 `[E]` 辨识采集：
   - 借助 MultiMesh 批量渲染 240+ 株山野红花、黄花、紫花、红蘑菇与林下灌丛，并点缀 Blender 精雕**溪畔夜光幽兰（flora_glow_orchid）**与**朱果奇蕨（flora_berry_fern）**；
   - 全图共 8 处可交互奇植科研点（如 `Wild Orchid` / `Water Lily` / `Red Mushroom` / `Mountain Lavender` / `Mountain Berry`），按 `[E]` 即可播放英文名称与地道例句，首次采集 `+5` 积分并于实战中恢复 `+5 ~ +8` 生命与 `+4` 护盾。
4. 实木山腰围栏 + 360° 立体梯田稻田、乡野村舍与远山叠翠：
   - 取代原透明空气墙：沿着全域边界 `x = ±52m`、`z = -112m / +26m` 围绕搭建贴地山腰木栅栏（含物理防越界碰撞体），确保玩家既不会穿出地图，又不阻挡齐腰以上的开阔视野；
   - 站在南栏观景牌或东岭梯田观景台向外望去，可见成片起伏有致的 3D 江南层叠稻田、向下汇入山下溪涧的水田支流、白墙黛瓦的乡野农舍（24 栋）、山下林木与 360° 青岚远山叠翠全景天际线。
