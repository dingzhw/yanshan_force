# 烟山基地 v0.7.1 阶段计划（语音热修）

基线　`v0.7.0` 本地验收包（仓库提交基线 `v0.6.7 / 4c3931d`）  
目标与范围　紧急修复跨机试玩（目标家用 Windows 11 电脑）所有英文单词无发音的阻断性问题：开启 Godot 4 导出包 `audio/general/text_to_speech=true`，并内嵌全游戏 247 条美式自然女声（`en-US-JennyNeural`）离线 `.ogg` 语音包至独立 PCK，实现断网且无系统英语语音包环境下 100% 清晰发音。  
延后事项　32 件藏品 2D 精美图鉴立绘与 Blender 3D 独立建模翻新（`v0.7.2`）；安全箱、战地委托与营地 3D 展台（`v0.8.0`）；5700G / Vega 8 性能与家庭首局/次日脱机回忆外部验收项在回传实测记录前保持 `false`。

| 阶段 | 阶段结果 | 验收依据 |
|---|---|---|
| 1 · 离线语音资产合成 | 新增可复现脚本 `tools/build_voice_pack.py`，为全游戏 247 条英文文本（175 词库 + 16 教材句 + 32 藏品 + 生灵/探索）预合成 `en-US-JennyNeural` 单声道 24kHz `.ogg` 并生成 `game/data/learning/voice_manifest.json` | 全部 247 个 `.ogg` 非空且校验 SHA-256，总包增量控制在 5 MB 以内；`THIRD_PARTY.txt` 如实标注来源与家庭离线教学用途 |
| 2 · 双通道发音与导出修复 | `game/project.godot` 开启 `audio/general/text_to_speech=true`；`main.gd` 接入专用 `voice_player` 优先播离线 `.ogg`、缺失时回退系统 TTS；`combat.gd` / `cipher_terminal.gd` 统一改用 `has_english_voice()` 摆脱对 `tts_voice_id != ""` 的强依赖 | 新增单元测试验证：175 词 + 16 句 + 32 藏品 100% 命中离线 `.ogg`，即使强制清空 `tts_voice_id` 依然能正常发声与触发听音题 |
| 3 · 成品导出与实机核验 | 保护 `v0.7.0` 历史包，导出 `v0.7.1` Windows 试玩包与统一 `.cmd`；在**实际导出的 `YanshanBase.exe`** 上实测 `--startup-check` 确认 `tts_setting_enabled=true` 且离线语音流可加载，并跑通独立 PCK 全量回归与 `verify_packaged.gd` | 独立 PCK 全部回归 0 失败；成品资源校验逐条确认 247/247 个 `.ogg` 可解码；成品 EXE 启动无明显回退；ZIP CRC 与历史包哈希通过；隐私扫描 0 命中 |
