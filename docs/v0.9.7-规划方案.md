# 《烟山行动 · Yanshan Force》v0.9.7 规划方案

日期：2026-11-24  
承接版本：`v0.9.6`  
定位：**双地图 PBR 质感与零穿模重塑 · 烟山全量实体碰撞 · 雕塑级骨骼动画 NPC / 雾隐兵团 · 严苛游侠名望解锁门控**

---

## 一、实机反馈与核心痛点梳理

1. **阿萨拉沙漠质感单薄与多处穿模（首要攻关）**：
   - 地表此前仅由单张 `61KB` 沙图平铺，缺乏法线/粗糙度与陡坡岩壁过渡；
   - 建筑物缺少实景贴图法线；椰枣树残留发光黄蛋材质；金合欢伞冠单薄；零号大坝两侧峡谷翼墙为低模多面体；
   - 东北停机坪混凝土圆台无碰撞导致双脚陷地；高台密码箱、应急物资箱、荒漠吉普与弹药堆在沙坡处半埋/倾斜；水泥厂 1 号集装箱与高架钢桥空间过近。
2. **烟山基地景物穿模与粗糙模型/动画**：
   - 旧版 `tea_terraced_hedge`（光滑荧光草球）与 `mossy_boulder_cluster`（贴青石板砖纹的球石）及石灯、青石凳、坡面倒木（部分悬空）、大杜鹃丛均缺少实体碰撞，玩家可直接穿行；
   - 烟山 360° 远山全景正中存在垂直接缝；山溪岸边呈现硬切深灰带；营地 3D 展台木面单薄；
   - 营地联络官「陈向导」仍为 4 方块简易拼装，烟山雾隐突击兵与狙击卫仍为刚体八角桶与摆锤腿。
3. **游侠人物解锁门控过松**：
   - 老存档中虽名望为 `0`，但因宽松旁路条件导致全部 5 位游侠默认亮出形象，违背“未达标前以‘？’立绘隐藏、达标后逐位解锁”的规划。

## 二、开源资产采集与 Blender 5.3 资产管线

- 新建 [`tools/fetch_v097_cc0_assets.py`](../tools/fetch_v097_cc0_assets.py)，采集并核验 **17 套 Poly Haven CC0 1.0 资产**：
  - **9 套 1K PBR 贴图组（27 张漫反射/OpenGL法线/粗糙度）**：`coast_sand_01`、`gravelly_sand`、`cliff_side`、`gravel_road`、`clay_plaster`、`old_sandstone_02`、`plaster_grey_04`、`aerial_grass_rock`、`mossy_rock`（落盘 `game/assets/pbr_v097/`）；
  - **8 套摄影测量 3D 模型**：沙漠组 `namaqualand_boulder_02/03`、`namaqualand_cliff_01`、`wild_rooibos_bush`；烟山组 `rock_07`、`rock_moss_set_02`、`shrub_01/02`。
- 使用 **Blender 5.3.0** 运行三套全自动管线脚本：
  1. `tools/upgrade_v097_ahsarah_pbr.py`：世界盒 UV + PBR 替换 + 摄影测量岩崖/巨石/灌木 + 去发光椰枣 + 枝冠金合欢；
  2. `tools/upgrade_v097_yanshan_nature.py`：重塑立体枝叶龙井茶丛与摄影测量苔藓花岗岩，并导出 `v097_yanshan_nature.glb`；
  3. `tools/build_v097_characters_and_anims.py`：融合 Quaternius CC0 + Blender Studio CC0 雕塑头模 + UAL 骨骼动作，产出 `npc_chen_guide.glb`、`v097_mistbound_assault.glb` 与 `v097_mistbound_sniper.glb`。

## 三、引擎落地与验收标准

1. **阿萨拉沙漠**：8 通道多层次 PBR 空间着色器（兼顾 GL Compatibility / Forward+ 8 采样器上限）、大坝双侧实心摄影测量岩崖、GPU 合批 231 处灌木散石、停机坪 22° 倒角实心碰撞、8 处新增平坦垫台 + `max_ground_height` 贴地 + 水泥厂 1 号集装箱移位。
2. **烟山基地**：`YanshanSceneryColliders` 统一承载 240 处实心静态碰撞、倒木两端取低高贴地、地表陡坡三平面苔岩着色、溪岸苔草渐隐羽化、360° 镜像无接缝远山、红木绒布黄铜 3D 展台。
3. **角色与动画**：陈向导与雾隐突击/狙击兵全量切入骨骼动画，同步外推雾隐词盾深度消除枪管穿盾。
4. **严苛游侠门控**：`lore_codex_ui.gd` 与 `rangers.gd` 双端统一门控——初始仅开放少羽；陈向导需序章通关或 ≥1 次委托；林听风/苏青禾/竹影严格按名望 `300 / 600 / 900` 逐位揭晓。
5. **10 套源码回归测试 + 10 张 1280×720 实机验收截图 + 4 层 Windows 独立包验真** 全部零失败通过后发布 `v0.9.7`。
