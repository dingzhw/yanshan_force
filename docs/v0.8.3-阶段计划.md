# v0.8.3 阶段计划 · 游侠「少羽」与 `[V]` 主动技能、烟山名望委托与人物小记角色卡

- **日期**：2026-11-21
- **开发基线**：`v0.8.2_dev2`（`c259f12`）
- **核心目标**：落地 2026-11-20 试玩反馈第 13 条完整游侠主角架构，为 `v0.9.0` 多游侠招募切换打好可扩展底座：

1. **R1 · 可扩展游侠注册体系与存档扩展（`game/scripts/rangers.gd` / `rules.gd`）**
   - 存档无损兼容扩展 `active_ranger`（默认 `"shaoyu"`）、`unlocked_rangers`（`["shaoyu"]`）、`reputation`（烟山名望）、`character_cards`（人物小记目录）、`bounties_completed`。
   - 建立统一 `RANGERS` 数据表，默认解锁 **游侠「少羽」**，同时预置 3 位 `v0.9.0` 名望可招募游侠档案预览（林听风、苏青禾、竹影）。
2. **R2 · 默认游侠「少羽」`[V]` 主动技能「天生神力」**
   - 按 **`[V]`** 键发动「天生神力」：第一人称重拳砸地动画（`weapon.gd`）+ 3D 金土震地波纹冲击环与扬尘 VFX + 合成重击震地音效 `skill_slam.wav` + 轻度镜头震动（遵循「减震动」开关）。
   - 将半径 `7.8m` 内的雾隐帮常规词兵 **震倒在地持续 1.5 秒**（`word_soldier.gd` 新增倒地态：向后倾倒平躺、停火停走、取消瞄准激光、词盾清晰暴露便于补枪），Boss 与古洞循音石卫受冲击触发短暂硬直打断；冷却 **30 秒**。
   - **键位解耦**：`[V]` 专属归属游侠主动技能；匕首近战保留 `[2]` 切刀 + 左键挥砍，并支持 **鼠标中键** 快捷近战挥刀，零键位冲突。
   - **专属技能 HUD**：右下角武器卡上方新增「⚡ 游侠·少羽 | [V] 天生神力」技能栏，就绪时鎏金高亮，冷却中实时显示剩余秒数与充能进度条。
3. **R3 · 营地联络员「陈向导」随机委托、「烟山名望」与「人物小记 / 角色卡」**
   - 正式战斗行动中营地帐篷旁常驻联络员「陈向导」（序章模式自动让位无重复），每局随机派发 1 项「烟山委托」（肃清营地、天生神力震倒 2 敌、破译 2 箱、5 连击、击败 B 区首领或古洞石卫），达成即刻结算「烟山名望」与行动币并弹窗祝贺。
   - 图鉴新增第 3 个页签 **「👤 人物小记」**：集中展示我方游侠档案（含「少羽」与后续名望游侠预告）与雾隐帮/秘境关键敌人小记（击败铁面词卫、玄铁词尊、古洞石卫或攻克首座营地自动解锁）。
4. **R4 · 自动化回归、720p 视觉核验、清洁白名单打包与实包验收**
   - 扩充 `combat.gd`、`economy.gd`、`slice.gd` 与 `verify_packaged.gd` 全面覆盖 `[V]` 技能震倒 1.5s / 30s 冷却、键位解耦、名望委托、人物小记解锁与 `skill_slam.wav`（35/35 WAV 解码）。
   - 截取 720p 实机验证图（技能 HUD 与震地倒地瞬间、营地委托 NPC 弹窗、图鉴「👤 人物小记」页签），导出 `v0.8.3` 独立包并执行四层实包验收与隐私扫描。
