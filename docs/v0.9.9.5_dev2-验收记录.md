## 四、中文 Windows Forward+ 启动闪退（`0xc0000374`）根因修复与压测

- **现象与崩溃转储定位**：双击 `开始烟山试玩.cmd` 显示 Godot 启动界面数秒后偶发直接闪退（实测裸 Vulkan 全新冷启动 10 次失败 5 次）。解析 Windows 崩溃转储（`.dmp`）确认故障线程位于 `glslang` 着色器解析栈，原因为 Godot `4.7.2` Windows 官方构建在中文区域设置（`Chinese (Simplified)_China.936`）下由 `WorkerThreadPool` 多线程并发编译着色器时竞态调用非线程安全的 `msvcrt!setlocale`，触发 `ntdll.dll` `0xc0000374`（`STATUS_HEAP_CORRUPTION`）。
- **修复方案**：在 `game/project.godot` 显式配置 `[threading] worker_pool/max_threads=1`，并在 `smoke.gd` 与 `tools/verify_packaged.gd` 锁定回归检查。
- **修复后连续压测结果（总计 28/28 PASS · 0 闪退）**：
  - 源码全新冷启动（Vulkan）：**15/15 PASS（0 失败）**
  - 源码全新冷启动（D3D12）：**5/5 PASS（0 失败）**
  - 独立成品 `YanshanBase.exe` 默认 Forward+ 全新冷启动：**5/5 PASS（0 失败，wall `14.1–14.2s`）**
  - 独立成品模拟真实双击无参启动（只读克隆旧存档与缓存，持续运行 14s）：**3/3 PASS（0 失败）**
