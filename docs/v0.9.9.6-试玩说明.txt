烟山行动 · Yanshan Force v0.9.9.6（v0.9 质量收口正式版）试玩说明
===================================================================

本版本完成整个 v0.9 系列质量收口与性能/存档/工程治理，包含全部 v0.9.9.6_dev1~dev3 新特性与以下五大收口升级：

1. 全量 GLB 重复贴图去重与发行包瘦身
   - 将跨 23 个 `.glb` 资产重复内嵌的 PBR 贴图通过标准 glTF 2.0 相对外部 URI 统一归并至 `assets/shared_pbr/` 与 `assets/pbr_v097/`，在保证 Forward+ 与 GL Compatibility 双后端 100% 画质零退化的前提下，大幅压缩 `.godot/imported/`、PCK 与 Windows 发行压缩包体积。

2. 冷启动加速与首进战区卡顿尖峰治理
   - 主菜单遮罩期间自动暂停隐藏主世界 3D 渲染管线（右侧 3D 沙盘通过独立 SubViewport 流畅渲染不受影响），同步延迟加载单人序章 3D 道具与阿萨拉 28 只荒漠生灵直至实际切图/进章，显著缩短冷启动进入主菜单耗时；
   - 作战部署时自动在首 3 帧静默预热敌军/首领骨骼模型、词盾与战斗特效着色器，大幅压低首进营地与 B 区首领战时的单帧尖峰。

3. 升级前安全备份防覆盖保护 & 3 独立本地存档槽位
   - 升级旧存档前自动创建并回读校验 `profile-backup-pre-v3.json`；若备份写入或校验失败，立即中止迁移覆盖、开启只读保护并在界面显著警示，确保历史存档零损坏；
   - 新增 **3 个完全独立的本地存档槽位**（槽位 1 直接兼容全部历史 `profile-v070.json` 旧档，槽位 2/3 独立保存于 `profile-slot2.json` / `profile-slot3.json`，当前槽位记录于 `save-slots-meta.json`），支持家庭双人或亲子轮流游玩互不干扰！点击左侧「存档槽 ▾」或进入 ⚙ 设置面板底部即可一键切换。

4. 阿萨拉高负载性能巡检、本地学习遥测与核显一键复测工具
   - 自动性能巡检升级为 4 段闭环（自由靶场纯训练 + 正式行动开箱撤离 + 烟山四景帧时 + 阿萨拉零号大坝/巴克什集市/行政堡垒三景高负载帧时）；
   - 存档内新增轻量级本地运行遥测 `session_telemetry`（仅保存最近 30 局的耗时、求助次数、正确率与结束原因，100% 离线本地）；
   - 新增一键 **`核显目标机复测.cmd`**（面向 Ryzen 7 5700G / Vega 8 等核显设备），双击即可自动以 GL Compatibility + 低画质完成全部 7 场景巡检并汇总报告至 `diagnostics/`。

5. 承接全部 v0.9.9.6_dev1~dev3 试玩升级
   - 全阵营 6 套高精 PBR 骨骼模型与 1:1 角色小传立绘、烟霞古洞落地/阴刻先人壁画/洞口零穿模密封/远山柔化、开镜与遇敌自动先发音（音形义联动）、首领战零重复单词、敌军 4 阶段动态台词（106 条多声线中文语音）与第 4 阶段小兵畏惧退避 AI（首领免疫）。

快速启动方式：
- 双击目录中的「开始试玩.cmd」（默认 Forward+，游戏内按 F6 可切换低画质）
- 核显或老设备建议双击「低负载启动.cmd」（GL Compatibility 渲染模式 + 低画质）
- 自动化 7 场景帧时巡检：双击「性能巡检.cmd」或「核显目标机复测.cmd」（报告写入 diagnostics/，不改动玩家存档）
- 常用按键：WASD 移动 / 鼠标瞄准射击 / 右键开镜 / [X] 随时重播当前单词读音 / [C] 蹲伏 / [Z] 趴伏 / [G] 烟雾弹 / [P] 或 [F5] 切换第一人称与第三人称 / [F] 交互 / [V] 游侠技能 / [F1] 战况与按键速查

备注：
- 本版本仅供个人/家庭离线英语学习试玩使用；开源可分发核心与家庭试玩限定资产的清晰替换边界详见包内 THIRD_PARTY.txt。
