## 一、试玩痛点与设计决策

| 编号 | 试玩反馈 | 根因诊断 | v0.9.8 最终方案 |
|---|---|---|---|
| 1 | 词盾面积过大挡住精雕角色，但缩小后又担心看不清英文 | 旧版 `2.00m × 0.70m` 不透明白板直贴胸前（`y=1.34, z=0.88`），遮挡全部躯干、手臂与步枪 | **混合最优解：头顶紧凑半透明全息词牌 + 胸甲嵌入式发光晶核**——头顶 `1.54m × 0.54m` 暗钢半透明玻璃 + 发光细框 + 粗体白字粗描边（面积精简 >40%、50m+ 清晰且支持双行词组零重叠），胸甲同步内嵌六棱能量晶核；打胸甲躯干或打头顶词牌皆算 2 枪破盾，头部完全暴露一枪爆头 |
| 2 | 用刀砍敌兵时血条完全不掉，砍满刀数突然瞬间清空死亡 | `combat.gd` 虽逐刀扣除了 `best_soldier.hp`，但 `word_soldier.gd` 的 `_refresh_hp_bar()` 对非 Boss 士兵只读取 `shield_layers / max_shield_layers`，完全忽略了 `hp / max_hp` | 修复 `_refresh_hp_bar()` 取 `min(hp/max_hp, shield_layers/max_shield_layers)`，每刀实时缩短血条并按绿→橙→红渐变，同步显示 `HP XX/XX` 数值与上升红色立体伤害飘字（`-18`/`-14`）；同步支持匕首劈砍古洞循音石卫实时扣血 |
| 3 | 古洞循音石卫外观粗糙怪异，且只会在洞里来回走直线 | 旧版 `v082_bosses.glb` 为畸形石球与鹿角棍拼装；`PATROL_OFFSETS` 4 个巡逻点近乎共线 | **立绘级 Blender 5.3 重塑 + 盲猎 Boss 机制升级**：基于 CC0 英雄人体解剖 + 棱面凿刻 + Poly Haven 512px 实景砂岩/玄武岩 PBR 烘焙 `v098_cave_warden.glb`（冷峻石雕面容、电青双眸额纹、菱形蓝核、双鸢形巨型石盾、迈步双腿）；参考 *Minecraft Warden* 与 *RE4 Garrador*，实装 **6 点环洞折线巡哨 + 1.65s 停步侧耳倾听**、**盲冲撞壁破防（横向闪避诱其撞壁震开双盾 2.6 秒）**、**射洞壁弹响声源诱敌** 与 **二阶段 `<50% HP` 可跳裂地冲击波** |
| 4 | 正面看陈向导很奇怪，帽子与头部没贴合好 | 官方立绘 `chen_guide.png` 本就无帽；旧版强行叠加倾斜宽檐帽与穿脸球体发芯且身高基准错位 `6cm` | 严格对齐 `1.72m` 头骨基准，彻底移除奇异宽檐帽与穿脸发芯，基于真实颅顶网格挤出贴合发壳 + 偏分背梳花白短发层叠发束（炭灰 + 鬓角银丝）、暖日晒老练肤色、规整折迭金褐围巾、双筒望远镜与肩部对讲机/黄铜口哨 |
| 5 | 所有阵营与首领语音都是同一个人的声调 | `build_cn_voice_pack.py` 中 7/8 角色复用了相近的 3 个男声底音且仅微调 `-2Hz..-10Hz` | 启用 5 位不同中文神经配音底音（`Yunxi` / `Yunjian` / `Yunyang` / `Yunxia` / `Xiaoxiao`）+ 真实声道共振峰移调（`asetrate/atempo`）与专属空间声学滤波，为全部 8 大阵营/首领打造频谱跨度 `864Hz–4601Hz` 的立辨声线（扩至 `66` 条 OGG） |

## 二、修改文件清单

- 资产构建工具：
  - `tools/build_cn_voice_pack.py`（8 角色独立声线 + 3 条循音石卫新机制台词 -> `66` 条 OGG）
  - `tools/build_v098_cave_warden.py`（立绘级 6 关节精雕砂岩古洞循音石卫 -> `game/assets/slice/v098_cave_warden.glb`）
  - `tools/build_v097_characters_and_anims.py`（去帽立绘级精修陈向导 -> `game/assets/slice/npc_chen_guide.glb`）
- 核心脚本：
  - `game/scripts/word_soldier.gd`（头顶紧凑暗钢全息词牌 + 嵌入式发光胸核 + 匕首逐刀血条/数值/立体飘字修复）
  - `game/scripts/combat.gd`（接入近战立体伤害飘字与精简提示栏文案）
  - `game/scripts/cave_warden.gd`（接入 `v098_cave_warden.glb` 6 关节驱动、6 点环洞巡哨停步倾听、盲冲撞壁破防、岩壁弹响声源诱敌、二阶段可跳冲击波、近战匕首判定与相机广告牌血条）
  - `game/scripts/main.gd` / `game/scripts/rules.gd`（版本号升至 `0.9.8`，挂接石卫近战劈砍与洞壁弹响诱敌回调）
- 测试与验收：
  - `game/tests/combat.gd` / `game/tests/slice.gd` / `tools/verify_packaged.gd` / `game/tests/capture_v098.gd`
