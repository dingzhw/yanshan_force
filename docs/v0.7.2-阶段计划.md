# 烟山基地 v0.7.2 阶段计划（藏品美术大翻新）

基线　`v0.7.1` 本地验收包（含 247 条美式女声离线语音，仓库提交基线 `v0.6.7 / 4c3931d`）  
目标与范围　彻底替换早期“方框/圆环/通用小方块”占位藏品美术：为全部 32 件战利品分配一一对应的独立美术 ID，在本地 Blender 4.5 中逐件构建雕塑级多材质 PBR 3D 模型（单包 `v072_collectibles.glb`）并同源渲染 32 张 256×256 博物影棚 2D 透明图标，同步升级 `[I]` 3D 检视台支持鼠标 360° 自由拖拽旋转、滚轮缩放与三点影棚布光。  
延后事项　营地 3D 奇珍展台、加密安全箱与随机战地委托（`v0.8.0`，直接复用本版 32 件 3D 模型）；分单元星级看板与换词包工具（`v0.9.0`）；5700G / Vega 8 性能巡检与家庭首局/次日脱机回忆外部验收项保持 `false` 待实测。
