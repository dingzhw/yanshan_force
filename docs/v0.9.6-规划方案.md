## 一、需求背景与核心目标

围绕 `v0.9.5` 实机截图反馈，聚焦登录门面视觉冲击力与角色收集探索仪式感，一次性落定四大体验跃升：

1. **未解锁人物显示“？”神秘立绘，解锁后揭晓真容**：
   - 新档仅默认解锁主角「游侠·少羽」形象；
   - 其余 13 名四大阵营人物在达成各自「档案 I」前统一显示暗钢风兜帽特工「？」加密立绘（`game/assets/portraits/locked_mystery.png`，`512×640`）、`LOCKED // ?` 与 `??? · 未解锁人物`，并在人物卡片与专页清晰展示解锁条件与实时进度条；
   - 达成「档案 I」门槛即刻解锁高清真容与全名，同时将四大阵营画廊统一校准为居中 4:5 比例，彻底消除 2/3/4 人阵营卡片的裁头现象。
2. **超高清 AI 立体地形作战沙盘（1600×900）**：
   - 使用生图管线专门绘制 3 张无字、风格统一且带全息等高线质感的超高清 3D 俯瞰立体地形图：
     - `map_yanshan_hd.png`：江南翠岭望稻亭与直升机坪（中上）、鲸塘中心小学红跑道操场（左下）、诚庄村白墙黛瓦石拱桥河港（右中）；
     - `map_ahsarah_hd.png`：北非零号巨坝碧蓝蓄水库与双穹顶雷达行政堡垒（中北/右上）、巴克什绿洲古城（左下）、哈夫克高原火箭发射台（右下）；
     - `map_story_hd.png`：晨光江南梯田溪谷、悬崖凉亭与烟霞古洞洞口；
   - 铺设于真实起伏的 `48×28` 3D 微地形网格上，配枪钢围边沙盘机身、全息经纬网格、动态激光雷达扫描线、鼠标微视差与 3D 抛物线数据连线。
3. **8 处定制 3D 立体旋转金属地标标志**：
   - 彻底告别旧版平面文字/emoji 标牌，在每处据点精建独立 3D 旋转金属/全息发光立体标志（拉丝钛钢底座 + 发光双陀螺环 + 脉冲雷达波 + 定制雕塑主体）：
     - 烟山基地（翡翠翼盾晶钻）、阿萨拉堡垒（琥珀六棱装甲要塞核心）、剧情序章（金色星芒指南棱镜）；
     - 鲸塘中心小学（立体学院山花柱廊徽章 + 3D 金属锁）、诚庄村河港（立体水乡铁锚 + 3D 金属锁）、巴克什古城（砂岩穹顶尖塔 + 3D 锁）、哈夫克航天禁区（轨道火箭三尾翼 + 3D 锁）、古洞秘闻（秘境晶棱 + 3D 锁）。
4. **现代枪械机械风战术登录界面**：
   - 左侧 1/5 命令导轨与底部悬浮部署台全面升级为暗炭枪钢配色、`2–3px` 锐利倒角、`4–5px` 荧光左侧导轨、`YANSHAN FORCE // SYS v0.9.6` 机匣铭牌、`00/01/02` 战区编码及机械触发式出击按钮。

## 二、技术架构与性能保障

- 3D 沙盘继续运行于独立隔离 `SubViewport`（`own_world_3d = true`），进入对局瞬间自动切换为 `UPDATE_DISABLED`，保证局内 0 额外帧率开销；
- 所有新增超高清资产（1 张加密立绘 + 3 张 1600×900 地形图）经 Godot `--editor --import` 正式导入并由 `tools/verify_packaged.gd` 逐项核验完整打入 `YanshanBase.pck`。
