# 烟山基地 v0.8.5 阶段计划

- **日期**：2026-11-21
- **开发基线**：`v0.8.4`（`6037cf7`，已推送 `origin/main` 并打标，工作区干净，源码 9 套件 517/517 PASS）
- **目标与范围**：落实「大烟山」面积 3 倍扩张方案 A（`180m × 240m`）、营地空间疏散与云顶演武坛建设，并同步解决 `2026年11月21日-v0.8.4试玩.md` 两项体验精修：
  1. **「大烟山」3 倍可玩面积扩张与营地科学布局（`layout.gd` / `slice_world.gd` / `minimap.gd`）**：
     - 围栏内可玩边界由 `104m × 138m`（`14,352 m²`）扩展为 **`180m × 240m`（`43,200 m²`，精确 `3.01×`，`X∈[-90, 90], Z∈[-200, 40]`）**；
     - 6 座雾隐帮营地间距由 `25–42m` 拉开至舒朗的 **`62–176m`**，彻底消除营地拥挤与视野/仇恨串联；
     - **烟霞古洞与迷踪竹石阵**整体平移至西侧独立竹林幽谷（`YANXIA_CAVE_CENTER = (-72, -100)`，距所有战斗营地 `≥64m`）；
     - 北端高台开辟 **直径 `38m` 的开阔「云顶青石演武坛」**（`CLOUD_ARENA_CENTER = (8, -180)`，平整青石广场 + 8 根盘龙青石柱 + 头顶零树冠遮挡），为 `v0.8.6` 机密「玄铁词尊」与终极技「天地万象」预留史诗舞台；
     - 重写 `fast_height_grid`（覆盖 `[-100..100] × [-210..50]`）、无缝外延 `OuterRiceValley` 与 `355m` 四重远山环带，优化 `_ground()` 构网与植被分块，严控 Draw Call 保 `Vega 8 / GL Compatibility` 流畅；
     - 同步升级 `minimap.gd` 比例尺并新增主要地标中文简标（`营`/`望`/`洞`/`坛`/`撤`），全链重排 `world_loot.gd`、`exploration.gd`、`wildlife.gd`、`prologue_chapter.tscn`、`prologue.gd`、`performance_tour.gd` 与全量 9 套件测试坐标。
  2. **Blender 4.5 新增江南人文与演武坛地标（`tools/build_v085_landmarks.py` → `game/assets/slice/v085_landmarks.glb`）**：
     - 精雕 5 组低面数 PBR 江南地标：三孔青石拱桥（`bridge_multi_arch`）、东岭茶亭（`tea_hill_pavilion`）、烟山摩崖石碑（`cliff_stele`）、云顶演武坛盘龙青石柱（`arena_dragon_pillar`）与演武坛石栏台沿（`arena_altar_rim`）。
  3. **同步精修 `v0.8.4` 试玩问题 #1 · 古洞循音石卫受击与 1.5 秒潜行机制重构（`cave_warden.gd` / `rangers.gd`）**：
     - 彻底移除“击中核心 / 累计伤害触发晕厥”与所有长晕厥机制；
     - **被击中核心瞬间**：石卫立刻 X 型合拢双臂护住核心，并立即朝玩家施展声波攻击反击；
     - **1.5 秒潜行静默脱搜**：玩家进入潜行/静默不发声（蹲伏 `[C]` / 匍匐 `[Z]` / 静止不开火）持续 **`1.5 秒`** 后，石卫即放弃搜索回归巡逻并重新放开双臂，再度暴露 `0.30m` 核心；
     - `[G]` 烟雾弹提供掩护并帮助玩家快速消声脱搜（不再长晕）；少羽 `[V]` 天生神力仅短暂震开石卫双臂 **`1.0 秒`**（不晕厥）。
  4. **同步精修 `v0.8.4` 试玩问题 #2 · 枪械 3D 挂件后移至瞄准镜侧边下方枪体（`weapon.gd`）**：
     - 将挂件挂耳后移至瞄准镜左侧下方后上机匣枪体（夹在左手护木与右手握把之间的空档），确保腰射、跑动、开镜、换弹前后两手均零穿模接触。
