推荐先试的组合

环境：Ground 015地面 + Rock Moss Set 01苔石 + Old Military Crate旧箱体，先把A至B做成统一风格。枪械：优先试Various Small Arms的一把步枪几何，配合独立手臂；Animated Guns Pack作动作导入备选。前者更接近所需轮廓，后者更容易建立动作流程，最终画面都需要加工。[S03] [S04] [S05] [S09] [S19]

目前未确认一套同时满足“免费开放许可、半写实、枪与手臂齐全、完整动作、直接适配本项目”的现成包。最大的缺口是枪械、手臂、动作和材质之间的匹配；其次是符合江南气质、适合核显的竹林和阔叶树整树模型。

两项看似合适、暂不优先采用的资源

L49 First-Person LMG

免费，有9段枪体动画和内嵌PBR贴图，GLB与Blender源文件齐全。但没有手臂，页面列约125k三角面、298个部件，且采用限制原始文件再分发的自定义许可。作者标注AI辅助制作。对于Vega 8和可持续维护的开放资源路线，当前不优先采用。[S14]

FPS PS1 Animated Glock

带手臂、动画与Blender文件，页面列CC0；目前下载需至少1加元。它的PS1复古风也与此次画面目标不一致。列出它是为了说明“许可开放”与“免费取得”是两回事。[S15]

开源资源省在哪里，仍要投入在哪里

可以省下

岩石扫描、树皮与地面纹理绘制、箱子造型、人体基础动作以及枪械基础几何。

仍需制作

地形、道路与场景摆放；统一尺度和色调；模型碰撞；持枪与换弹匹配；英文护板；交互和反馈。

必须实测

720p能否读清词牌；枪是否挡字；词兵绕掩体是否卡住；植被、阴影与透明叶片对Vega 8的负担。

下一轮资源试样怎么验收

  1. 环境小样：一段10–20米土路、两种近景树形、两三块苔石、一个旧箱；观察地面接缝、远近比例、坡脚与碰撞。
  2. 枪械小样：只选一把，完成可观察的持枪、射击、换弹与瞄准；先确认手指握持、弹匣位置与枪口方向。
  3. 词兵小样：同一个角色完成走、跑、受击与倒地；护板词组完整显示。先在20米内验证读词，再决定距离。
  4. 目标电脑：先用720p低画质验证30帧目标，记录帧时间和最低表现；不把开发机的顺畅当成Vega 8验收。
  5. 通过后再铺地图：把合格的素材和设置用于A至B，保留来源、许可文本、原始包哈希和修改记录。

上述距离、材质分辨率和试样规模是工作起点。尚未下载或读取模型文件，因此没有把具体帧率、显存占用、导入成功或动作兼容写成已通过。
