# 《烟山行动》v0.9.4 规划方案 · 主角「游侠·少羽」精品全骨骼角色与动作全面重塑

制定日期：2026-11-23  
版本定位：承接 `v0.9.3`（`ec61701`），专注将主角「游侠·少羽」从刚体拼接木偶原型全面升级为 **55 骨平滑蒙皮 + 24 段真实骨骼动作库 + 精准双手抵肩据枪 + SpringBone 物理围巾** 的端游级风格化 3D 主角，并确立后续 `v0.10.0` 多游侠复用的标准化角色工业管线。

## 一、目标问题与设计定版（方案 B）

针对 `v0.9.3` 试玩反馈的 3 项核心痛点：
1. **模型像刚体木偶**：改为 CC0 开源精品人体/战术拓扑底座 + Blender 4.5 焊接平滑与多骨骼软蒙皮，彻底消除刚体硬缝、直立木桩腿与硕大绿色砖块背包；
2. **动作机械僵硬**：弃用纯 `sin(phase)` 摆动，采用 Quaternius UAL + KayKit（均 CC0）真实人形步态世界空间四元数重定向，引入错步战斗站姿、骨盆律动、8 向走跑冲刺/侧移/后退、真实蹲伏、贴地俯卧与起跳落地；
3. **握枪姿态怪异与 `[V]` 步枪指天**：在 Blender 4.5 中以真实 YS-04 卡宾枪坐标直接求解双臂解析 2-Bone IK 与五指局部弯折，并配备专属 `Weapon_R` / `Weapon_Back` 挂接骨骼，实现右手紧握握把、左手托举护木、枪托抵肩窝，以及切刀/发动 `[V]` 重拳时自动斜背挂步枪。

外观确认定版（**方案 B · 阳光风格化 3D PBR 质感**）：
- 16–17 岁健朗少年比例（`1.75m`），层次感乌黑微扬短碎发 + **戴眼半透明琥珀战术护目镜** + 单耳骨传导耳麦与拾音麦；
- 标志性 **朱砂红编织游侠围巾 + 4 节物理飘带（`Scarf_01`→`Scarf_04`）**；
- 青黛墨竹短款收腰战术夹克（卷袖露出前臂肌肤 + 炭灰护腕缠带 + 左肩鎏金云纹臂章）+ 暗炭灰三联弹匣 MOLLE 轻胸挂与迷你对讲机；
- 贴身流线型山野突击小背囊（暗炭灰/军绿/沙棕 X 型束带）；
- 深棕半指皮革手套 + 古铜加固指虎护拳 + 修身炭灰多袋战术工装裤/硬壳护膝/深棕越野作战靴。

## 二、技术架构

1. **Blender 4.5 建模与四元数重定向管线（`tools/build_v094_shaoyu_rigged.py`）**：
   - 合法采用 CC0 1.0 公有领域资产（Quaternius Ultimate Modular Men `Swat`/`Casual`、Quaternius Universal Animation Library Godot Standard、KayKit Character Animations 1.1），许可全文归档于 `game/licenses/` 并在 `game/THIRD_PARTY.txt` 完整署名；
   - 归一化 `ShaoyuArmature`（`scale = 1.0`、`1.75m`、55 根骨骼：49 个人体与五指骨骼 + 4 根围巾物理骨 + `Weapon_R` / `Weapon_Back` 挂接骨），统一导出 `game/assets/slice/player_shaoyu.glb`（`9,897` 面，核显零压力）；
   - 世界空间四元数重定向 18 段真实步态/近战/换弹动画 + Blender 解析 2-Bone IK 精校 6 段精准枪械/俯卧/少羽重拳动画（共 24 段）。
2. **Godot 4.7.2 现代 TPS 骨骼控制（`game/scripts/player_body.gd`）**：
   - `Skeleton3D` + `AnimationTree`（`AnimationNodeBlendTree`：`LowerLocomotion` 15 态平滑过渡 + `UpperCombat` 7 态骨骼过滤分层融合 + `FullBodySlam` `AnimationNodeOneShot` 独立重拳触发）；
   - `AimSpineModifier`（`SkeletonModifier3D`）实时叠加视角俯仰与 Q/E 探头至脊柱/胸腔/头部；
   - `TwoBoneIK3D` 左臂护木挂点就绪 + `SpringBoneSimulator3D` 驱动红围巾随奔跑与风速实时飘动；
   - `BoneAttachment3D` 精准同步 YS-04 涂装/瞄具/消音器/弹匣与精雕战术匕首（`tactical_knife.glb`）；1P 隐藏头部与上半身装具，完整保留平滑蒙皮双腿与战靴。
